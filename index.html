Projects

01

Agentic RAG for Enterprise Document Intelligence

Problem

Enterprise teams sat on 1000+ documents but couldn't get trustworthy answers — pure semantic search missed exact terms and codes, pure keyword search missed meaning, and neither could say when it wasn't sure.

Built

A multi-agent RAG system on LangGraph that combines BM25 keyword search with dense vector retrieval, then validates and routes intelligently: if semantic search comes back weak, the system falls back to keyword search, and if confidence is still low, it escalates to human review instead of guessing. Every answer ships with source attribution and a confidence score.

Result

~20% higher answer accuracy and ~30% fewer hallucinations versus a single-strategy baseline, with reliable, source-grounded responses across the full document set.

LangGraph Hybrid Search (BM25 + Vector) Elasticsearch Claude Confidence scoring Fallback routing
02

AutoInsight

Real-time agentic vehicle diagnostics

Problem

Vehicle diagnostic data is dense and jargon-heavy; users needed answers conversationally, in real time, with the context of their previous questions preserved.

Built

A streaming diagnostics assistant on a LangGraph agent core, served through a Flask-SocketIO backend so responses stream token-by-token to 50+ concurrent users. It calls tools to pull diagnostic data, keeps conversation memory with checkpointing across turns, and runs on AWS Bedrock for managed model access.

Result

A responsive, multi-turn assistant that turns raw diagnostics into plain-language answers — with the concurrency, memory, and error-handling needed to run in production rather than a notebook.

LangGraph AWS Bedrock Flask-SocketIO Real-time streaming Tool calling Conversation checkpointing
03

Automotive Requirements Automation

Problem

Writing System and Software Requirements specs to automotive standards is slow, repetitive, and easy to make inconsistent — but it can't be sloppy, because compliance depends on it.

Built

A multi-agent LangChain pipeline that generates complete, ASPICE-aligned System and Software Requirements from domain templates and regulatory constraints, using constraint-based prompting and a validation agent to keep output consistent and standards-compliant.

Result

Sharply reduced drafting time and more consistent documentation across engineering teams, without losing the compliance rigor the domain demands.

LangChain Multi-agent orchestration Claude Sonnet & Haiku ASPICE compliance Constraint-based prompting
04

Team Knowledge Enablement

Problem

Planning, execution, and sales teams kept re-asking the same questions because product knowledge was scattered across documents — onboarding was slow and answers were inconsistent.

Built

An end-to-end ingestion pipeline — S3 upload triggers an n8n workflow that chunks, embeds, and inserts documents into a vector database, with file monitoring, format validation, and retry handling — topped with a RAG chatbot that lets any team query the shared knowledge base directly.

Result

Closed cross-team knowledge gaps and cut onboarding time, with a self-serve system that stays current as new documents land.

n8n Pinecone FastAPI S3 RAG Vector DB
