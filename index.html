Projects

01

Call Insight Engine

AI call intelligence platform · independent project, built and deployed on AWS

Problem

Multilingual sales calls — Hindi, Gujarati, Marathi, Telugu, Kannada — hide compliance red flags, pricing violations and agent misconduct, and manual review doesn't scale. Speech-to-text alone was ~85% of per-call cost.

Built

An end-to-end platform that transcribes calls, summarizes them, extracts CRM enquiry fields and flags violations. A tiered LLM pipeline screens with a low-cost model and escalates to a stronger one on flags, low confidence or long calls, with prompt caching and a grounding gate that rejects any flag whose verbatim evidence quote isn't in the transcript. I benchmarked STT providers on real call audio, moved to Soniox (~14x cheaper than AWS Transcribe), and built a WER/CER evaluation harness and an 8 kHz telephony test corpus. Shipped with JWT auth and 4-role RBAC, audit logging, a React dashboard (review queue, agent analytics, cost tracking), idempotent two-way CRM integration and AWS CDK infrastructure; 300+ automated tests.

Result

A pilot on 750+ real calls in one month at ~INR 0.15 per call. Call-connection detection auto-filtered 90 of 181 non-conversation recordings (voicemail, busy tones, call screeners), all confirmed on manual review, and I fixed an Indic-script validation bug that had inflated LLM spend by ~15%.

AWS Bedrock (Claude) OpenAI GPT Soniox STT FastAPI React Lambda · DynamoDB · CDK Prompt caching Grounding gate
02

BMS Predictive Anomaly Detection

EV battery management for a global automotive OEM

Problem

A global automotive OEM needed to catch battery anomalies predictively, across 190M+ sliding-window samples of multivariate telemetry (60-timestep input sequences) — far beyond what a single machine or a simple threshold can handle.

Built

TCN-LSTM and CNN-LSTM models trained on 8×H100 GPUs with PyTorch Distributed Data Parallel, fed by Zarr-backed datasets with NVMe and shared-memory caching. Asymmetric anomaly thresholds from Extreme Value Theory (EVT/GPD) per temperature bin, plus distributed gradient boosting (XGBoost / LightGBM / CatBoost) via Dask on Databricks GPU clusters. A DTC confidence-scoring pipeline using Wilson lower-bound lift across 240M+ rows in PySpark, a Captum Integrated Gradients explainability module, and MLflow tracking with Unity Catalog I/O.

Result

Delivered as a production system for the OEM, with explainable outputs and tracked experiments — and recognised with Tata Elxsi's 2026 Extra Mile Award.

PyTorch DDP 8×H100 Databricks PySpark Dask EVT / GPD Captum MLflow
03

Agentic RAG for Enterprise Document Intelligence

Problem

Enterprise teams sat on 1000+ documents but couldn't get trustworthy answers — pure semantic search missed exact terms and codes, pure keyword search missed meaning, and neither could say when it wasn't sure.

Built

A multi-agent RAG system on LangGraph that combines BM25 keyword search with dense vector retrieval, then validates and routes intelligently: if semantic search comes back weak, the system falls back to keyword search, and if confidence is still low, it escalates to human review instead of guessing. Every answer ships with source attribution and a confidence score.

Result

~20% higher answer accuracy and ~30% fewer hallucinations versus a single-strategy baseline, with reliable, source-grounded responses across the full document set.

LangGraph Hybrid Search (BM25 + Vector) Elasticsearch Claude Confidence scoring Fallback routing
04

Drone Security System

Multimodal agentic video surveillance · independent project

Problem

Object detection alone floods operators with ambiguous alerts, and nobody can watch hours of footage to find what mattered. The system had to stay real-time while still reasoning about what it saw.

Built

A real-time agent that ingests RTSP or recorded drone footage and runs a 6-node LangGraph pipeline — perceive, contextualize, rule check, LLM judge, alert, log — combining YOLOv8, ByteTrack, CLIP embeddings and VLM captions. A hot-reloadable YAML rule engine (after-hours intrusion, loitering, gate tampering) escalates ambiguous alerts to Claude Haiku on Bedrock, which rules them genuine or false positive; per-zone cooldowns deduplicate alerts. Slower VLM captioning runs asynchronously in a thread pool with a local Moondream2 fallback, and backpressure-aware streaming drops the oldest frames on live feeds but blocks on recorded files.

Result

Detection stays real-time, and hybrid retrieval over CLIP vectors (ChromaDB) and structured events (SQLite) with LLM intent parsing powers a Streamlit dashboard — live alerts, an event timeline, and multi-turn natural-language search over footage. 120+ tests.

LangGraph AWS Bedrock (Claude Haiku) YOLOv8 + ByteTrack OpenCLIP ChromaDB SQLite Streamlit Docker
